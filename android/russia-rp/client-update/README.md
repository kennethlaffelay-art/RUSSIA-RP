# Автообновление RUSSIA RP

Клиент 1.7.18 (код 42) устанавливается поверх 1.7.17 с тем же именем пакета и тем же сертификатом. После первого запуска лаунчер проверяет очередную версию в фоне. В безлимитной сети загрузка начинается автоматически. В сети с тарификацией лаунчер сначала показывает размер и запрашивает согласие. Установку подтверждает игрок. При возвращении из настроек разрешений лаунчер продолжает установку.

## Выпуск следующей версии

1. Увеличить код и номер версии клиента. Собрать полный APK с пакетом `com.russiarp.hudx` и подписать действующим ключом проекта.
2. В репозитории `kennethlaffelay-art/RUSSIA-RP` опубликовать стабильный Release с тегом вида `russia-rp-v1.7.19` и файлом `RUSSIA-RP-1.7.19.apk`. Указать фактический номер сборки. Для быстрой проверки через CDN приложить рядом `client-update.json` и пометить выпуск Latest. Формат файла показан в каталоге выпуска 1.7.18. Поля `size` и `sha256` вычисляются по подписанному APK.
3. Проверить переход с установленной предыдущей версии, сохранность данных и повторный запуск. При отсутствии метаданных на CDN лаунчер проверяет GitHub Releases, пропускает публикации кэша, черновики и предварительные выпуски.

Для сборки загрузочного клиента используйте `build.py --help`. Нужны исходный официальный APK 1.7.17, JDK, Android SDK Platform и Build Tools. AndroidX FileProvider уже находится в базовом APK. Заглушка в `stubs` нужна только для компиляции. Модуль обновления загружается из отдельного DEX. Сертификат и имя пакета обновления дополнительно сверяются на устройстве до открытия системного установщика.

Раздел `qa` содержит проверки выбора версии, загрузки по частям, повторного использования скачанного файла и отказа при несовпадении контрольной суммы.
