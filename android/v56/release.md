Исправление повторяющегося вылета при загрузке карты Арзамаса на ARM64. Увеличена ёмкость пула, который игровой движок использует, когда распределяет объекты карты по секторам. Все объекты карты сохранены.

Можно установить поверх v5.5. Версия Android-приложения 1.6.8 (24). Для входа нажмите «Играть». Кнопка «Отправить крашлог» находится в настройках. Проверка на физическом OnePlus CPH2747 остаётся открытой.
